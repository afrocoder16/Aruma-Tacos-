# Aruma Tacos & Tequila — Marshall concept site

A responsive, no-build HTML/CSS/JavaScript concept for the new Aruma location at 900 Clarice Ave, Marshall, MN 56258.

Open `index.html` directly, or serve this folder with any static web server.

## What is included

- Immersive responsive hero with layered 3D motion
- Scroll reveals, parallax, floating details, and animated counters
- Interactive category menu and full-menu dialog
- Cocktail tasting-note selector
- Reservation request demo flow
- Responsive navigation and real Google Maps directions
- Mobile layouts down to 390px
